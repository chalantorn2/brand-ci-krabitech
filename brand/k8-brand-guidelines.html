02 / LOGO

Pixel K

ตัว K ทึบที่แขนล่างแตกออกเป็น pixel ไล่จากใหญ่ไปเล็ก เล่าเรื่องการเปลี่ยนธุรกิจจริงในกระบี่ให้เป็นดิจิทัล เส้นทแยงของแขนบนกับ pixel ชี้ทิศเดียวกัน คือไปข้างหน้า

  1. A

    Stem · ความมั่นคง

    ก้านตรงสี Navy คือพื้นฐานที่แน่น ทีมท้องถิ่นที่ลูกค้าไว้ใจได้ ดูแลต่อหลังส่งงาน

  2. B

    Arm · การเติบโต

    แขนทแยงสี Electric Blue พุ่งขึ้นขวาบน แทนเทคโนโลยีที่ช่วยให้ธุรกิจโต

  3. C

    Pixels · Physical สู่ Digital

    แขนล่างแยกเป็นบล็อก 14 → 12 → 8 ไล่ลงขวาล่าง แทนการแปลงงานหน้าร้านจริงให้อยู่บนระบบ

  4. D

    Spark · รายละเอียดเล็กๆ

    pixel สีอ่อน 2 จุดเป็นจังหวะเบา ใช้สีรองเสมอ ห้ามตัดทิ้งในขนาดใหญ่ ตัดได้เฉพาะ favicon 16 px

Primary · Reversed

บนพื้น Navy ก้านเปลี่ยนเป็นขาว pixel รองเปลี่ยนเป็น Cyan

Vertical

Symbol

07 / PIXEL SYSTEM

Pixel คือองค์ประกอบกราฟิกของแบรนด์

นำ pixel จากแขน K มาใช้เป็น pattern บนปก แบนเนอร์ และโพสต์ ทำให้ทุกงานจำได้ทันทีแม้ไม่มีโลโก้

Local AI for Krabi businesses

1 · ไล่ขนาด

pixel เล็กลงเมื่อห่างจากต้นทาง อัตรา 14 → 12 → 8 → 7 ห้ามใช้ขนาดเท่ากันหมด

2 · ทิศทางเดียว

กระจายลงขวาล่างตามแขน K เสมอ วางชิดมุมหรือขอบ ไม่ลอยกลางงาน

3 · สีจำกัด

ใช้ Blue เป็นหลัก ผสม Sky / Cyan ไม่เกิน 1 ใน 4 บล็อก ห้ามใช้สีนอก palette

12 / MOTION
Stem นิ่ง pixel เคลื่อน
การเคลื่อนไหวของแบรนด์มาจากโลโก้โดยตรง ก้าน K คือความมั่นคงจึงอยู่นิ่ง ส่วน pixel คือการเปลี่ยนแปลงจึงเป็นส่วนที่ขยับ ข้อความและ UI เคลื่อนแบบนุ่ม ส่วน pixel ขยับแบบขั้นบันได

    

      
01
ก้าน K ไม่ขยับ
ในงานทั่วไปก้าน K อยู่นิ่ง ยกเว้น logo intro ที่ก้านค่อยๆ ขึ้นจากฐาน ห้ามหมุน เด้ง หรือบิดโลโก้

      
02
Smooth กับ Steps
ข้อความ การ์ด และ UI ใช้ ease-out ที่นุ่ม ส่วน pixel ใช้ steps() ให้ขยับทีละช่องเหมือนหน้าจอ

      
03
ทิศเดียวกับหาง K
pixel เข้ามาในแนวทแยงจากซ้ายบนไปขวาล่าง ส่วนข้อความเลื่อนขึ้นไม่เกิน 8–16 px ไม่ใช้การบินเข้าจากขอบจอ

      
04
สั้นและเงียบ
งาน UI ใช้เวลาไม่เกิน 400 ms ส่วน 900 ms ขึ้นไปใช้กับโลโก้และวิดีโอเท่านั้น และทุกงานต้องรองรับ prefers-reduced-motion

    


    

      
Logo intro · 1.3 s
        

        
      

      
Loader · loop 1.2 s
        

        
ใช้แทน spinner ทั่วไป เฉพาะเมื่อรอนานกว่า 400 ms

      

      
UI micro-motion
        
Hover: ยกขึ้น 2 px · 160 ms
List: ไล่ทีละ 60 ms
Pixel: steps(4) · 400 ms

        
      

    


    

      
--kd-ease-outcubic-bezier(.2,.8,.2,1) · เข้า / หยุดนิ่ง (ค่าหลัก)

      
--kd-ease-incubic-bezier(.5,0,.75,0) · ออกจากจอ

      
--kd-ease-in-outcubic-bezier(.65,0,.35,1) · ย้ายตำแหน่ง

      
--kd-ease-pixelsteps(4,jump-end) · pixel เท่านั้น

      
--kd-dur-*instant 100 · fast 160 · base 240 · slow 400 · brand 900 mshover สี = instant · ปุ่ม = fast · การ์ด / dropdown = base · modal / หน้า = slow · โลโก้ / วิดีโอ = brand · stagger 60 ms
