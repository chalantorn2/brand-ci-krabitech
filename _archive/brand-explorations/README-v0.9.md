# Krabi Digital Solutions — Corporate Identity (draft v0.9)

Two logo directions, fully specified. Open `krabi-digital-brand-book.html` in a browser for the full guideline.

| | Concept A · Karst K | Concept B · Pixel Horizon |
|---|---|---|
| Mark | K from limestone tower + peak + Andaman wave + orange pixel | Pixel karst skyline, green tops, mango sun, 3 waves in a circle |
| Primary | Andaman Blue `#00AEEF` | Sky Blue `#00A6ED` |
| Action / links | Deep Andaman `#0077C8` | Deep Sky `#0A7CC2` |
| Ink | Night Sea `#0B2540` | Ink Navy `#102A4C` |
| Secondary | Lagoon Teal `#14B8A6`, Aqua Mist `#7FE3D8` | Karst Green `#1F9E7A`, Andaman Sand `#F4E7CF` |
| Accent (≤5%) | Longtail Orange `#FF8A3D` | Sunset Mango `#FFB23F` |
| Fonts | Bai Jamjuree / IBM Plex Sans Thai / IBM Plex Mono | Anuphan / Noto Sans Thai / JetBrains Mono |

All fonts: Google Fonts, SIL Open Font License (free for commercial use).

**Before print:** lockup SVGs use live text that loads the font from Google Fonts. Open them in Figma/Illustrator with the font installed and convert text to outlines before sending to a printer. Mark-only files are pure vector and ready to use. CMYK values are approximations; proof with the printer.
